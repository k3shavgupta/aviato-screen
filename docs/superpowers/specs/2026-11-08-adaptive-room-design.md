# Adaptive room display

Selected by Keshav on 8 November 2026: large artwork while music plays, a clock
and quote while idle, and a quieter night layout.

## Display

Add an `adaptive` profile to the native 1920×1080 renderer. Preserve `focus`,
`minimal`, `album`, `ambient`, and `legacy` as selectable alternatives.

- Daytime playback: a 640×640 cover at the left; large, wrapped track title,
  artist and album at the right. A compact clock and date remain at the top.
  Weather and Bitcoin form a quiet footer. Use an album-derived accent only
  for a small playback indicator. Missing art gets a vinyl placeholder.
- Daytime idle: a large clock at the left and a generous quote at the right,
  rotating on the existing ten-minute schedule. No empty Spotify card.
- Night, 23:00–08:00 IST: a centered, dim clock and date on black. Night takes
  priority over playback. Preserve the existing overnight polling pause.
  The power controller keeps the panel awake for `adaptive` so this layout is
  visible. Other profiles retain their 23:00–08:00 power-off schedule.

Use the existing Liberation Sans font, evergreen #151916 background, ivory
#ebece5 text, sage #a0aa9c secondary text, and #d4c494 fallback accent. Night
uses black with muted #747e78 clock and #535d57 date. Avoid motion, technical
status rows, and decorative labels. Weather/price failures remain visible as
unavailable or last-known values; failed Spotify status retains metadata with
a visible last-known label during daytime playback.

## Implementation and verification

Keep layout and state signatures in `adaptive-screen.h`, sharing existing
collectors, text drawing, and the artwork cache. Decode covers once to a
640-pixel square; downsample when drawing existing profiles. Separate header,
body, and footer damage regions. Repaint the whole screen on layout changes;
otherwise only regions whose visible content changed. Hide agent status and
disable its blink timer in the adaptive profile.

Compare incremental output byte-for-byte with a fresh paint across playback,
idle, missing art, long titles, source failure, quote rotation, and both night
boundaries. Verify hidden data does not cause night repainting. Run existing
C tests and ASan/UBSan; inspect previews generated by the actual renderer.

Activate by atomically replacing the verified executable and writing
`adaptive` to the profile file, then restart only the verified display process.
Rollback files are in `backups/2026-11-08-adaptive-before/`. This directory is
ignored by the parent home-directory repository; preserve a file backup rather
than adding the application to that unrelated repository.
